# Практическая работа 2 — витрина товаров

Откройте `GardenStore.sln` в Visual Studio 2022, дождитесь восстановления NuGet-пакетов и запустите проект `GardenStore.Web`.

Проект содержит каталог, серверные теги-фильтры, сессионную корзину, Bootstrap-alert и modal, демонстрационную админ-панель, локальные статические файлы и минификацию `site.css`/`site.js` при сборке.
